# MDD4All.DME.DataModels

Sample data models for MDD4All.DME, the object graph editor application.

Each folder is one small model, kept deliberately narrow so it shows a single thing: objects inside objects, lists and arrays, dictionaries with a complex key, read-only properties, data annotations, the DataType hints, an enum. The editor loads this assembly like any other data model - it is nothing the application knows about beforehand.
